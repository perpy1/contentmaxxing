# Cursor

Run `contentmaxxing install --agent cursor --path <creator-folder>` or use
`--scope user`. Open the creator folder and invoke `/contentmaxxing-start`.
Browse `/contentmaxxing-help` or use ordinary language with the umbrella skill.

The installer creates `.cursor/skills/` entrypoints from the shared command
catalog. Cursor supplies the reasoning; the common engine saves and validates
the work. See [installation](../../docs/INSTALL.md) for scope, updates, runtime
setup, and the distinction between generated-file tests and host-session tests.
