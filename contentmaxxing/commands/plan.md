# Plan

Read editorial-planning and inspect the bank and workflow cadence. Run `plan week`.
In external mode it saves a planning task. Complete its contract using the
creator context, cited candidate pool, history and measurements. Import that
result to save the plan, then explain the strategy, actual choices, deferred
ideas, open questions and unfilled capacity. Configure cadence only from creator
direction. Do not fill empty slots with generic advice or treat planning as
publishing authorization.

First inspect `progress` for a saved plan. Reuse it unless the creator requests
a new plan (`plan week --new`). Repeated calls reuse unfinished planning tasks or
their saved plans. Explicit selections should be persisted with `ideas select` before
planning; selected platform/format/job choices are retained. Show the saved
Topic + Format + Job table, angle/payoff and plan file, then recommend `create`
with that plan ID. Planning and creating are separate stages; create executes
the saved briefs. A plan originating from a weekly run resumes that same run.
