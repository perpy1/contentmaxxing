# Compound

Read compound and the measured winner evidence. Resolve the content ID from
the requested post or `analytics winners`. Run `compound <id>` and inspect the
pending compound task. Execute the shared skill against its frozen inputs and
import its contract-shaped response. Inspect the resulting opportunities in the
bank. Every derivative adds context, proof,
story, argument, format, or utility. If evidence is insufficient to call it a
winner, say so. Do not fake a baseline or label an ordinary rewrite a new angle.
Draft a chosen follow-up only when requested, preserving its parent and evidence.

If useful captured evidence is missing from an uncommitted pending task, attach
the exact passage with `tasks cite <task-id> --source <source-id> --start-line <n>
--end-line <n> --quote <text>`, then re-read the task. This expands evidence within
the saved budget while preserving the parent, measurements and previous excerpts.
Do not invent facts, drop prior proof, or restart the analysis merely to add a citation.

Separate ready ideas from those with `development.gaps`; show their new value
and the specific evidence needed. Capture and resolve those gaps before writing.
Repeated `compound <id>` calls resume or return saved results. An intentional
new pass uses `--new`; `--query <terms>` refines related-source retrieval for that
pass. It sees existing angles so it can develop unused value. Completed empty
assessments remain completed; do not endlessly retry them to fill the bank.
The explicit extractive mode offers labeled heuristic prompts only.
Read the assessment in the task and `data/reports/compound/<task-id>.md` when
summarizing the result. An explicit creator request to abandon the analysis can
use `tasks cancel <task-id> --reason <reason>`; committed ideas are preserved.
