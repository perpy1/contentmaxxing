# Create

Use the saved plan named by the creator or the current progress checkpoint. Run
`create --plan <id>` (without an ID only when exactly one plan is unfinished).
If none exists, use `plan`; if several exist, let the creator choose. Read the
plan's Topic + Format + Job slots. Once execution starts, the linked run is the
authoritative snapshot; do not silently replan or change its choices.

Execute pending tasks using their native platform skills, creator voice and
evidence. Import results, then repeat `create --plan <same-id>` until complete
or a real input gap stops progress. The shared scheduler supplies the analytics
brief and checkpoints each slot. COMPLETED means execution finished; inspect
the actual content IDs and shortfalls, since an empty plan produces no drafts.
Link saved drafts, surface uncertainties, and recommend `review`. Never approve
or publish as part of creation.
