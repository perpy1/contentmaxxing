# Progress

Run the read-only CLI `progress`. Show workspace, current stage, saved library
counts, unfinished work and `next_action.reason`. Counts are lifetime library
totals, not a completion percentage. Link the actual plan/drafts/report when
available. Recommend one action using the host's native invocation. Do not
execute it merely because the user asked for progress. `status` is an alias.

Home follows this procedure too. For a new creator show WELCOME.md and its two
choices. For a returning creator show the live state beneath the CONTENTMAXXING
title. Do not replace live state with static onboarding choices or a full menu.
