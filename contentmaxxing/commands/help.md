# Help

Show the native command menu supplied by the wrapper, using `config/commands.json`
for descriptions. Explain Capture → Create → Compound in one sentence. If the
creator is new, recommend `start`. For an existing creator, inspect `overview`
and recommend one useful next step. They can also ask in ordinary language;
use the same command procedures. Keep terminal plumbing out of their workflow.

Group the menu: navigation (`start`, `next`, `progress`, `resume`); core loop
(`capture`, `plan`, `create`, `review`, `publish`, `analytics`, `compound`);
batch (`week`); focused tools (`mine`, `ideas`, `draft`, `article`); help/aliases
(`help`, `status`). Lead with start for newcomers and next for returning creators.
