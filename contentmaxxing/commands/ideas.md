# Ideas

Read idea-bank. Use `ideas list` with relevant query, status, platform or job
filters. Show useful choices in plain language. To select, resolve the idea ID
yourself and use `ideas select <id> --platform <platform> --format <format> --job <job>`.
Keep the topic separate from its expression and intended behavior. Retrieve
existing work before suggesting new research. Never silently change creator identity.

For “find the story/proof about ...”, use `sources search` and inspect relevant
lines. Attach additional evidence through `ideas cite` before starting a draft.
Explain when search is incomplete; never mistake a missing lexical match for
an empty library.
