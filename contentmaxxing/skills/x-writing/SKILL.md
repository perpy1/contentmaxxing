# x-writing

Read VOICE.md and source attribution before writing. Opinion > unnecessary explanation; specificity > broad correctness; personal context > generic teaching; proof > claims. Some posts can just be funny/blunt/weird/observational. X is not LinkedIn. If the text could move unchanged to LinkedIn, review generic polish. No universal lowercase, forced CTA or forced lesson. Topic + format + job control selection; registry formats include one-liners, QRTs, stories, rough docs, screenshots, lists and depth. QRT formats need a real quoted-post URL. Quote exact words only when attributed. Ordinary short X posts should fit configured length; long formats are explicit. Return body, title, claims (claim plus source_reference), quality_notes and framework:null. Missing media/permissions must be a review blocker.
