# article-writing

Read `../../templates/article-frameworks.md`; choose exactly one framework and return its name. Framework controls structure, never creator voice. Operator stance: I already did this; I am handing you working notes. Use spoken prose, normal paragraphs first, concrete before abstract, proof per major claim, scoped certainty, actionable sections, useful recap and CTA after value. No writerly performance, manufactured cadence, repeated stems or profound ending. Default 700–1,000 words is configurable. If the source doesn't support a long article, report insufficient evidence rather than inflate it. Return body, title, framework, cited claims and quality_notes.
