# Article framework library

Choose one structure based on the job. Never replace creator voice with the framework's archetype.

| Framework | Structural sequence | Best fit |
| --- | --- | --- |
| HADES | scene → principle → proof → application | calm teacher; buying psychology/behavior |
| BUZZ | experiment → rule → caveat → apply box | friendly researcher; authority/trust/psychology |
| LOGAN | command → mistake → mechanism → do this instead | sideline coach; platform tactics |
| JUAN | result → hidden mechanism → stages → execution | campaign lead; repeatable outcomes |
| EP | consensus flip → scope fence → playbooks | practitioner dumping the repo; large guides/distribution |
| FREDERICK | do → don't → help → accelerate → biggest mistake | field engineer; painful processes |
| SERIES / TECHNICAL OPERATOR | series promise → personal proof → Part N → named principle → build with me → anti-pattern → examples → maintenance → next part | systems actively being built |

Spoken prose and normal paragraphs. Default 700–1,000 words; the workspace config can override. One proof object per major claim. Scope certainty. A useful section can be used this afternoon. End with a useful recap; any CTA follows delivered value.
