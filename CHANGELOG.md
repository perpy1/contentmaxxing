# Changelog

## 0.1.0 — early testing release

- Installable agent kit with a shared orchestrator, 19 skills and native command
  adapters. Codex has native acceptance coverage; other hosts need testing.
- Curated interview and file-dump onboarding, creator brain, voice, pillars and
  offer documents, and a retro welcome image with a terminal fallback.
- Source capture, cited topic mining, idea bank, Topic + Format + Job planning,
  and review drafts for X, LinkedIn, TikTok, articles and Substack.
- Revisions, scoped creator feedback, voice proposals and resumable weekly work.
- CSV/manual analytics, measured-winner follow-ups, experiments and provenance.
- Portable local records, export/restore and upgrades that preserve creator edits.
- Optional Typefully adapter with mocked tests; no publishing account required.
- Package verification and CI that tests the exact installed wheel.

This is a testing release, not a claim of demonstrated creator growth or universal
host compatibility. See [current status](STATUS.md) for evidence and limitations.
