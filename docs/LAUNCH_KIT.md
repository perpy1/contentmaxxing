## Longer introduction

The content treadmill is expensive: post, forget, start from zero tomorrow.

CONTENTMAXXING starts with material you already have. A client question. A build
log. A disagreement on a call. A mistake you finally understand. It preserves
that material, finds distinct topics, and helps you decide what to make with it.

Every piece has a topic, a format and a job. Those choices carry into the draft.
Your creator profile, writing samples and corrections guide the voice. When you
have real performance data, it can compare outcomes and propose follow-ups that
add context, proof, story, format, argument or utility.

The product is an installable agent kit delivered through skills. The methods
live in Markdown; your sources, ideas, drafts and learning stay in inspectable
files. Your existing AI supplies the reasoning. You can publish manually and
import metrics, or add an optional connector later.

This is an early testing release. Codex is the first host exercised end to end;
other adapters need native testing. I want feedback from creators on the parts
that matter: useful topic selection, recognizable voice, grounded drafts, and
whether the next session actually builds on the last one.

## A demonstration to record

1. Open a fresh creator folder and run `$contentmaxxing-start`.
2. Show the interview/file-dump choice and supply a small source you can share.
3. Confirm the creator profile and show a topic linked to its original passage.
4. Review one draft, give a precise correction, and show the revised piece.
5. Start a fresh session, run `$contentmaxxing-resume`, and show the saved work.
6. Point testers to `docs/BETA_TEST.md` and the feedback issue template.

If using fictional fixtures, label them on screen. Keep performance claims out
of the demonstration unless there are real measurements to show. The offline
demo is a workflow check with scripted responses, not a writing-quality demo.

## Claims for this release

Supported: open-source MIT kit; 19 skills and 19 actions; interview/file intake;
source-linked ideas; creator voice documents and corrections; review drafts;
local files and export; job-aware analytics; optional Typefully adapter; native
Codex trials with fictional creators; automated installed-package checks.

Still being tested: real creator voice/usefulness, fresh native sessions in other
hosts, desktop image display, live Typefully behavior and audience outcomes.
Avoid claims of guaranteed growth, autonomous publishing, universal chat-app
compatibility or a public package-registry install that does not exist.
